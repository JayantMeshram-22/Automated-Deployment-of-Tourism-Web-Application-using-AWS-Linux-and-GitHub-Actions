# 🌐 Cloud Computing-Based Information System for Tourism Village

## 📌 Project Overview

This project aims to develop a **Cloud Computing–Based Information System** to support and promote the growth of a **Tourism Village**.
The system provides a digital platform where tourists can explore village attractions, accommodations, local food, festivals, transportation, and other services.

⚠️ **Note:** This repository currently contains **only the frontend implementation** of the project. Backend services and cloud infrastructure will be added in future phases.

---

## 🎯 Objectives

* Promote tourism villages through a digital information system
* Provide easy access to tourism-related information
* Improve visitor engagement using a modern web interface
* Lay the foundation for cloud-based scalability and availability

---

## 🖥️ Frontend Features

* Home & discovery pages
* Tourism information pages:

  * Hotels & accommodations
  * Food & local cuisine
  * Festivals & events
  * Guides & travel planning
  * Transportation & shopping
* User authentication pages:

  * Login
  * Register
  * Forgot password
* Admin dashboard UI (frontend only)
* Responsive and user-friendly design

---

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and layout
* **JavaScript** – Client-side interactivity

